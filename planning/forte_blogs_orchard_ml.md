   `classifier` + `feature_encoder`, `vectorizer=None`,
   `taxonomy_transform="modernbert_logistic"`.

   `C=0.1`, `class_weight="balanced"`, `max_iter=1000`, `random_state=20260725`.

   A custom `CODE` tree defaults to `{CODE_raw_js: 1.0}` unless you pass
   `taxonomy_weights` / `profiles`. You must pass weights explicitly.

   `fusion_mode="variance_calibrated"`, when `orchard[embeddings]` is present
   and you do **not** inject `TfidfEmbeddingBackend()`. Do not force TF-IDF-only.
5. Missing neural extras must **fail loudly**. Do not set
