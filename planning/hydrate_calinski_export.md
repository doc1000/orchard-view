
### 4. Node-id sanity check (hard stop)

Canonical IDs are membership hashes. After `from_linkage`, assert:

- `tree.root_node_id == source["root_node_id"]` (same root hash for both trees; labels differ, IDs do not)
- a few sampled source node IDs (root, one internal, one leaf) exist in `tree.nodes`

If any mismatch: stop. Do not fuzzy-relabel.

### 5. Load and align phase3b matrices

For each tree, `np.load` the matching profile. Demo `load_matrix` is `archive["matrix"]` + `archive["tool_ids"]`.

Align **rows** to that tree’s linkage leaf order so `feature_matrix[i]` is the same item as `item_ids[i]`. Same length (457) is not enough if order differs:

```python
index = {tid: i for i, tid in enumerate(npz_tool_ids)}
rows = [index[tid] for tid in linkage_item_ids]
aligned = matrix[rows]
```

If the matrix is square, apply the same permutation to columns so the pairwise diagonal stays self-similarity/self-distance. Pass that array straight into the cutter as `X`. Do not convert to cophenetic / squareform / another embedding. Domain is distance-like (diag ~0); function is similarity-like (diag ~1). That is expected.

### 6. Exact Calinski `build_dynamic_cut` call (both trees)

```python

cut = build_dynamic_cut(
    tree,
    top_criterion="optimal",

    feature_matrix=aligned_matrix,  # matching phase3b profile, linkage order

    min_width=3,
    max_width=10,
    target_width=None,
    max_depth=5,

```

Run independently for **`domain` and `function`**. The live notebook last ran this on **domain only**. You must produce both.
